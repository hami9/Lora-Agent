# Competitive research

Decision date: 2026-11-04. This comparison covers the repositories named in the brief and adds MLX LM as an independent Apple Silicon training baseline. Each evidence link freezes the tree containing the README, source and license. The date is the latest default-branch commit observed through GitHub's API, in UTC month-day for 2026. All 12 repositories were unarchived at inspection. Recent commits establish activity, not support guarantees. Capability summaries describe upstream documentation. Integration cost, reuse choices and risks are engineering judgments. No backend was run for this comparison.

## What Lora owns

| Work | Owner | First evidence needed |
|---|---|---|
| Tokenization, template application, sampling and math kernels | Reuse the pinned engine in its private worker | Golden prompt token IDs, stop handling, reproducible generation envelope |
| Model identity, import, worker handshake and lifecycle | Integrate the engine with a verified artifact store | Interrupted import, malformed model, dead worker and incompatible version tests |
| Device fit, transparent fallback and pressure-aware admission | Implement core policy over backend estimates and OS probes | Matched-device fit decisions, measured peaks, uncertainty and refusal reasons |
| Tool scopes, approval integrity, cancellation and crash recovery | Implement one trusted core and platform adapters | A hostile document and replayed tool intent cannot cause an out-of-scope effect |
| Adapter personalization | Integrate a trainer only after model-specific qualification | Held-out improvement, exact provenance and adapter serving conformance |

Goose and Rig already offer extensible agent runtimes, and Jan and Ollama already serve local models. A credible differentiation would be a reproducible answer to “will this exact configuration fit?”, backed by a measured prediction error, alongside a trace that explains precisely which file operation was approved and performed. Ship a benchmark fixture and an adversarial task fixture for those claims. A Rust control plane alone cannot substantiate a throughput advantage.

## License and support gate

Inspect the license text at the pinned revision even if GitHub displays a single license or “NOASSERTION.” Jan's LICENSE references Apache-2.0. PMetal, Burn and Candle carry both MIT and Apache license texts. Keep selected license, notices, vendored dependency inventory and source revision for each bundled release. Re-evaluate the SDK, redistributable runtime, model weights, tokenizer, adapter and dataset licenses independently. An upstream MIT license on an engine establishes no redistribution rights over a model. Verify the final build's transitive notices and release artifacts before distribution.

## Remaining gaps

A repository reports available features across many builds. It does not establish concurrent availability for our worker, our exact checkpoint and a given machine. Compare backend-specific model tables, run the compatibility fixtures and record driver/OS identity before promoting a tuple. Package size, actual RSS, energy, throughput and recovery under memory pressure are unmeasured. No project was penalized for missing a feature outside its purpose.
